## What this command gives you

`/goal-status` is the operator-facing shortcut for this workflow: summarize goal contract, open work, review cycles, dirty state, and verification status. Use it when you want the guard's state, evidence, or review workflow in a form that is explicit enough to act on immediately.

Summarize the current Goal Mode state without editing files.

Include:

- Goal Contract
- Open todos
- Implementation status
- Verification Ledger
- Review Ledger
- Review cycles count
- Dirty/stale-review risks
- Next required action
